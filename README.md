# 全画面ブラウザ（Android）

GASで作ったページなどを、スマホ・タブレットの全画面で表示するAndroidアプリです。
店頭モニター向けに「上から下へ自動スクロール → ページ更新 → また上から」を無限に繰り返せます。

## できること

| 機能 | 内容 |
|---|---|
| 全画面表示 | ステータスバー・ナビゲーションバーを隠して表示。画面は常時ON（スリープしない） |
| 自動スクロールモード | ON の間は画面操作を受け付けず、「開始前の待ち時間 → 下までスクロール → 最下部で待つ → 更新」を繰り返す |
| 通常ブラウザモード | 自動スクロール OFF で普通のブラウザとして操作可能（戻るキーでページを戻る） |
| メニュー | 自動スクロール中は**ダブルタップ**、通常モードは右下のボタンか戻るキーで開く |
| メニューの中身 | URL入力、自動スクロールON/OFF、速度・待ち時間の調整、ブックマーク、ホーム画面ショートカット作成、再読み込み、終了 |
| ショートカット | ブックマークの「ホームに追加」で、そのページを直接開く起動アイコンをホーム画面に作成（自動スクロールONで起動 / 通常で起動 を選べる）。アプリアイコン長押しメニューにも上位4件が出ます |
| GAS警告バナー除去 | 「このアプリケーションは、Google Apps Script のユーザーによって作成されました」を自動で非表示にし、ページを画面いっぱいに広げる |
| **スライドショー（サイネージ）** | 登録した画像・PDF・Webページを順番に表示し続ける（下記） |
| 状態の復元 | 最後に開いていたURLと自動スクロールのON/OFFを、次回起動時に復元 |
| 店頭向けの安定化 | 通信エラーや読み込みが止まった場合も自動で再読み込み。WebViewが落ちても自動復帰 |

### 自動スクロールの設定（メニュー内）

- **スクロール速度**：10〜300 px/秒（初期値 60）
- **開始前の待ち時間**：ページ表示後、スクロールを始めるまで（初期値 3秒）
- **最下部での待ち時間**：一番下に着いてから更新するまで（初期値 3秒）
- **スクロール不要なページの表示時間**：1画面に収まるページの場合、この時間で更新（初期値 30秒）

## スライドショー（デジタルサイネージ）

店頭で、Webサイトと告知画像・チラシPDFなどを順番に切り替えて表示できます。
メニュー →「スライドショー設定（画像・PDF・URLの登録）」で設定し、「▶ スライドショーを開始」で再生します。

| 画面（タブ） | 内容 |
|---|---|
| 画像・PDF | 端末内の画像（JPG・PNG・WebPなど）やPDFを複数まとめて取り込み。ファイルはアプリ内にコピーされるので、元ファイルを消しても表示できます |
| Webページ | 表示したいURLをリストとして登録（表示名つき）。ブックマークからまとめて登録も可 |
| スライドショー | 表示する順番（↑↓）、スライドごとの秒数、一時的に表示しない（チェックを外す）を設定 |

- 取り込んだ画像・PDF、登録したURLは、自動でスライドショーの最後に追加されます（同じものを何回でも追加可）。
- **画像**：設定した秒数（初期値 10秒）表示して次へ。「画像を画面いっぱいに表示」ON で余白なし表示。
- **PDF**：1ページずつ設定した秒数（初期値 各10秒）で表示し、最終ページの次は次のスライドへ。
- **Webページ**：自動スクロールONなら一番下までスクロールし、**スクロール完了後 n秒**（初期値 5秒）で次へ。
  1画面に収まるページ・スクロールOFFのページは表示時間（初期値 30秒）で次へ。
  スクロール速度・開始前の待ち時間はメニューの自動スクロール設定を使います。
- 最後まで行ったら最初に戻って繰り返します。再生中は画面操作を受け付けず、**ダブルタップ**でメニューを開けます。
- 通信エラーで表示できないページは、エラー画面を出さずに次のスライドへ進みます。
- 再生中にアプリが再起動しても、スライドショーを最初から自動で再開します。
- 「スライドショーをホーム画面に追加」で、タップするとすぐ再生が始まる起動アイコンを作れます。

## ビルド方法

### A. Android Studio（おすすめ）

1. [Android Studio](https://developer.android.com/studio) をインストール
2. 「Open」でこの `kiosk-browser` フォルダを開く（初回は Gradle の同期に数分かかります）
3. 「AGPをアップグレードしますか？」と出たら、そのままアップグレードして問題ありません
4. 端末をUSBでつなぎ（端末側で開発者オプション → USBデバッグをON）、▶ Run で実行
5. APKファイルが欲しい場合：メニュー **Build → Build App Bundle(s) / APK(s) → Build APK(s)**
   → `app/build/outputs/apk/debug/app-debug.apk` を端末にコピーしてインストール

### B. GitHub Actions（PCにAndroid Studioを入れない場合）

このフォルダをGitHubのリポジトリにpushすると、`.github/workflows/build.yml` により自動でAPKがビルドされます。
Actions タブの実行結果から `KioskBrowser-debug-apk` をダウンロードして端末にインストールしてください。

## GASページについて

- GASのWebアプリは「外側のページ（script.google.com）」の中に「iframe（googleusercontent.com）」が2段入った構造になっています。
  このアプリはすべての iframe にスクリプトを注入し、実際にスクロールしている iframe を自動で見つけて動かします。
- 警告バナーは外側のページにだけ表示されるので、そこだけを非表示にしています（ページ本体には一切手を加えません）。
- デプロイの「アクセスできるユーザー」は **「全員」** にしてください。ログインが必要な設定だと、下記の理由で表示できないことがあります。

## Googleアカウントについて

Google は「アプリ内のWebView」からのGoogleログインをセキュリティ上の理由でブロックしています
（「このブラウザまたはアプリは安全でない可能性があります」と表示されます）。
そのため、このアプリにはGoogleログイン機能を入れていません。代わりの方法：

1. **（推奨）GASのデプロイを「全員」にする** — ログイン不要になり、店頭端末でも確実に表示できます。
   見せたくない情報がある場合は、URLに推測しにくいパラメータ（例 `?key=xxxx`）を付け、GAS側の `doGet(e)` でチェックする方法が手軽です。
2. **Chrome カスタムタブで開く** — Chromeのログイン状態を使えますが、自動スクロールやタッチ無効化などの制御はできなくなります。
3. **Googleのサインイン（Credential Manager）でアプリにログイン** — アプリ側で「誰が使っているか」は分かりますが、
   WebView内のGASページのログイン状態にはならないため、GASの「Googleアカウントを持つ全員」設定のページは結局開けません。

必要であれば 2 や 3 を追加実装できます。

## 店頭設置のヒント

- **アプリの固定（画面の固定）**：設定 → セキュリティ → 「アプリの固定」をONにすると、ホームボタン等でアプリから出られなくなります。
- **自動起動**：端末再起動後の自動起動が必要なら追加実装できます（Android 10以降は制限があるため、ホームアプリとして設定する方式になります）。
- 電源につないだまま使う場合は、端末の「バッテリー保護（充電上限）」設定をONにするのがおすすめです。

## ファイル構成

```
app/src/main/
├── java/com/enoffice/kioskbrowser/
│   ├── MainActivity.kt     … 全画面WebView、自動スクロール制御、スライドショー再生、メニュー
│   ├── SlideshowSettingsActivity.kt … スライドショー設定画面（画像・PDF取り込み／URL登録／順番・秒数）
│   ├── Slides.kt           … スライドのデータ保存、画像・PDFの読み込み
│   ├── Prefs.kt            … 設定・ブックマークの保存
│   └── ShortcutHelper.kt   … ホーム画面ショートカット
├── assets/
│   ├── kiosk.js            … 各フレームに注入するスクリプト（GASバナー除去・スクロール）
│   └── welcome.html        … 初回起動時の案内ページ
└── res/                    … 画面レイアウト・文言・アイコン
```

- アプリ名を変える：`res/values/strings.xml` の `app_name`
- パッケージ名を変える：`app/build.gradle.kts` の `applicationId`
- 動作環境：Android 8.0 以上、Android System WebView 94 以上（Playストアで更新してください）
